# CSS Showcase

Run with `cargo run -p tilt-ui-example-css-showcase`. The gallery demonstrates
border shorthands and patterns, cached image background filters, and animated
GPU effects. Animated previews run only while hovered or pressed.

Set `TILT_UI_CSS_SIZE=390x844` to inspect the responsive layout. Set
`TILT_UI_CSS_SCREENSHOT=/tmp/css-showcase.png` to save a screenshot after the
first two seconds.
