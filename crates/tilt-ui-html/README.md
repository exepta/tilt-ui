# tilt-ui-html

`tilt-ui-html` parses HTML documents and component templates for [TiltUI](https://github.com/exepta/tilt-ui). Its output feeds the component and Bevy runtime layers.

Applications should normally depend on the main [`tilt-ui`](https://crates.io/crates/tilt-ui) crate instead of this parser crate. Use `tilt-ui-html` directly when building custom template tooling or integrations.

The [project guide](https://github.com/exepta/tilt-ui#readme) explains `src-ui/index.html` and component templates.
