# tilt-ui-css

`tilt-ui-css` is the CSS parsing and styling crate used by [TiltUI](https://github.com/exepta/tilt-ui). It converts stylesheets into the rules consumed by the Bevy UI runtime.

Applications should normally depend on the main [`tilt-ui`](https://crates.io/crates/tilt-ui) crate to use CSS with components. Use `tilt-ui-css` directly only when implementing custom stylesheet tooling or integrations.

See the [project guide](https://github.com/exepta/tilt-ui#readme) and [CSS showcase](https://github.com/exepta/tilt-ui/tree/main/examples/css-showcase) for application examples.
